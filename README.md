# python-expenses-tracker
A simple Python script to track daily expenses and check the budget limit. 
Простой скрипт на Python для учета ежедневных расходов и контроля бюджета.
----------------------------------------------------------------------------------------
Учет расходов студента (Python)

📌 Возможности:

· Суммирует ежедневные траты пользователя.
· Работает в бесконечном цикле до ввода команды выхода (0).
· Анализирует итоговую сумму и выдает предупреждение при превышении лимита (3000 руб.).

🚀 Как запустить:

1. Скачайте файл expenses_tracker.py.
2. Откройте терминал и запустите: python expenses_tracker.py.
3. Вводите суммы трат по одной. Введите 0, чтобы увидеть результат.
